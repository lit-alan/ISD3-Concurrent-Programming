## Lab Exercise 4 :point_down:

Open the starter code for this exercise and observe a `Customer` class and a `Main` class. In the `Main`, 25 `Customer` objects are created and added to a list.

## Task1:
Write a method that will accept a list of `Customer` objects and will then sort the list by the `lastName`
field in ascending order. If two customers have the same `lastName`, sort them by `firstName`. The
method will then return the list of sorted objects (to main) where it is to be displayed on the console.
